### He decidido crear un aula virtual en moodle para así recopilar una gran parte de los conocimientos que hemos aprendido en este año de SMR1
#### Para acceder a este aula virtual tienes que seguir estos pasos
---
1. Descomprime la carpeta de Moodle
2. Accede a la carpeta y ejecuta el archivo *Start Moodle*.
3. Cuando se haya ejecutado en la consola, debes abrir tu navegador y escribir **http://localhost/**
4. En la pestaña de acceder debes escribir las siguientes credenciales:
   Nombre de Usuario: juanpedrofernandez
   Contraseña: Juan_Pedro1234
5. Cuando terminemos de utilizarlo, cierralo con el archivo **Stop Moodle**.
   
   Desde que ejecutes **Start moodle**, tardará un poco tanto en arrancar como en cargar la página.
