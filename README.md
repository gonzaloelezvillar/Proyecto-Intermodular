#### Para acceder a este aula virtual tienes que seguir estos pasos
---
1. Entra en el enlace de Drive y descarga la carpeta de: Moodle_Gonzalo_PIM.zip
2. Descomprime la carpeta de Moodle
3. Accede a la carpeta y ejecuta el archivo *Start Moodle*.
4. Cuando se haya ejecutado en la consola, debes abrir tu navegador y escribir **http://localhost/**.
5. En la pestaña de acceder debes escribir las siguientes credenciales:
   Nombre de Usuario: juanpedrofernandez
   Contraseña: Juan_Pedro1234
6. Cuando terminemos de utilizarlo, cierralo con el archivo **Stop Moodle**.
   
   Desde que ejecutes **Start moodle**, tardará un poco tanto en arrancar como en cargar la página.
