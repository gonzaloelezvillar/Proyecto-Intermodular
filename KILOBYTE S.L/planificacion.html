Cómo se organiza el trabajo

Qué módulo se usa en cada parte del proyecto y en qué fases lo ejecutamos.

06 · Módulos

Qué módulo se usa en cada parte

1

Sistemas operativos en red

Instalar y configurar los servidores y los equipos de la empresa.

2

Servicios en red

Poner en marcha la web, la base de datos y el resto de servicios.

3

Seguridad informática

Proteger con Sophos Firewall y el SAI, y configurar los equipos y la red para que sea más segura.

4

Itinerario personal para la empleabilidad

Crear la empresa: planes, contratos, leyes de la empresa, riesgos laborales, etc.

5

Computación en la nube y virtualización

Crear los servidores como máquinas virtuales y usar la nube (trabajando en alojar la base de datos en la nube).

Tecnologías

Con qué está construido el proyecto

Cada pieza del stack juega un papel concreto en el resultado final.

Servidor

Windows Server + DF Server

Software de servidor de archivos y dominio sobre máquinas virtuales: la base de la infraestructura de red de la empresa.

Datos

HeidiSQL

Gestión de la base de datos de la empresa, con 8 tablas que cubren clientes, equipos, facturas y contratos.

Seguridad

Sophos Firewall

Protección perimetral de la red corporativa: filtrado de tráfico y control de accesos.

Web

HTML · CSS · JavaScript

La web corporativa, la tienda con carrito y el chatbot, todo programado sin frameworks para aprender el funcionamiento de abajo arriba.

Nube

Firebase

Hosting del sitio, Authentication (email y Google), Firestore para usuarios y pedidos, y hosting de la web en kilobyte-sl.web.app.

IA

Gemini (Firebase AI Logic)

El chatbot del asistente de IA responde con modelos Gemini, con instrucciones de sistema que lo hacen experto en la empresa.

07 · Planificación

Fases de trabajo

  1. 1

    Diseño

    Definir logo, nombre, web y base de datos.

  2. 2

    Servidores y red

    Instalar sistemas y servicios en máquinas virtuales.

  3. 3

    Web y chatbot

    Crear la web, el registro de usuarios y el chatbot.

  4. 4

    Seguridad y nube

    Configurar firewall, SAI y copias de seguridad.

  5. 5

    Pruebas y entrega

    Comprobar que todo funciona y presentar el proyecto.
